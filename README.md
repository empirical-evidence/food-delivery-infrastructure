# Food Delivery Platform — Infrastructure

Репозиторий содержит инфраструктурные артефакты платформы.

## Структура

- docker-compose/          — для локальной разработки
- environments/            — описание окружений
- docs/                    — дополнительная документация

## Окружения

- dev  — разработка
- test — тестирование
- prod — продакшен

## Локальный запуск

cd docker-compose
docker compose up -d
